# 运账通 · 物流财务系统 V2

这是一个面向小微物流企业的本地可运行系统原型。新版参考原系统实际页面和业务字段重新设计，覆盖运单、调度、签收回单、应收应付、收付款、对账、费用、资金、发票、客户和经营报表。

## 启动

在 PowerShell 中运行：

```powershell
.\start.ps1
```

然后访问：

```text
http://127.0.0.1:8088/#dashboard
```

本地测试账号：

```text
账号：admin@logistics.com
密码：admin123456
```

## 已实现

- 全新账号登录页、登录错误提示、当前会话恢复、账号菜单与可靠退出；退出普通账号时同步清除财务授权，避免下一位使用者继承敏感权限；
- 全面重做导航、顶栏、经营卡片、业务表格、表单、弹窗和移动端视觉规范，并完善键盘焦点和小屏账号退出入口；
- 经营驾驶舱；
- 运单新增、搜索、筛选、导出和状态推进；
- 起点、终点按“省/市/区县”三级选择，并按区县中心点自动估算运输里程；
- 常用客户的收发货联系人、电话、区县、详细地址和常发货物一键带入；
- 发货信息和收货信息使用两个独立识别模块，分别粘贴后自动填写各自联系人、电话、详细地址和区县，避免串填；
- 发货和收货分别提供“高德地址导入”：支持高德分享文字、带地址/坐标的分享链接及短链接，识别地点名称、详细地址和所在区县；
- 运单查询支持完整运单号、复制出的“运单号＋日期”、客户、路线、司机和车牌，并自动解除状态筛选；
- 顶部全局搜索会自动识别 `WB` 运单号并进入运单结果，不再把运单号误送到财务应收查询；
- 从三联单复制“运单编号＋开单日期”等整段文字也能提取运单号并精确命中；
- 演示区县库外的省市区县也可动态导入；没有本地坐标时允许人工填写确认里程；
- 创建运单时司机和车辆均为可选项，默认不显示；需要时可选择已有档案或现场录入新司机、新车辆；
- 现场录入的司机、车辆可选择保存到档案，车辆同步记录车型和车长；
- 货物支持包装、件数、重量、体积和声明价值，费用支持运费、保险、装卸、上楼及其他费用自动合计；
- 物流运输三联单预览与打印：客户留存联、司机留存联、记账留存联；未填写的司机、车辆字段不会生成空栏；
- 三联单采用左侧发货人/公司、右侧收货人的布局，并包含付款、结算、交付、人民币大写、约定事项及签字盖章区；
- 调度看板、派车及签收状态联动；
- 财务专属区统一整合应收、应付、回款、付款、对账、费用、资金流水、发票和财务经营报表；

## 相比原系统的主要改进

- 统一页面层级和视觉规范，减少大额数字、状态和操作按钮的识别成本；
- 将运单、调度、签收、应收、回款和资金流水串成连续操作；
- 增加账龄、高风险应收、待办和现金流驾驶舱；
- 新增应收详情抽屉、操作时间线和自动核销反馈；
- 调度由单一表格升级为待调度、运输中、已签收看板；
- 运单路线精确到区县，自动带入常用客户资料并估算里程；
- 三联单按留存对象显示不同结算信息，空的司机/车辆信息自动收起，不显示道路运输经营许可证示例号，支持A4纵向打印；
- 车辆、司机和车队改为独立档案关系，适配自营、车队和临时外请三种运力；
- 增加客户贡献、账龄结构和线路毛利分析；
- 支持桌面端、平板和手机端；
- 移除对外部CSS和图片资源的依赖，离线也可运行。

## 说明

当前版本为无需安装前端依赖的可交互原型，业务数据保存在浏览器 `localStorage` 中，普通账号和财务授权分别保存在当前标签页的 `sessionStorage` 中。它不会改动原系统或原数据库。

演示版财务专属密钥：

```text
finance2026
```

账号登录与财务授权均只在当前标签页有效，关闭标签页后失效；退出普通账号时会同时撤销财务授权。当前实现用于本地原型演示；正式生产环境必须改为服务端身份认证和权限校验，并使用不可逆密码散列、登录失败限制、操作审计及密钥轮换，不能依赖前端代码保存账号或密钥。

### 高德地址导入

1. 在新建运单中，将发货方的高德分享内容粘贴到左侧发货模块，点击“高德地址导入”；收货方内容粘贴到右侧收货模块，两个模块不会交叉填写。
2. 直接复制的“地点名称＋省市区＋门牌号＋联系人＋电话”无需地图 Key 即可识别。
3. 带有 `position`、`location` 等坐标和地址参数的高德链接，可直接识别区县与详细地址。
4. 高德短链接由本地 `server.py` 安全展开；升级后必须重新运行 `start.ps1`，不能继续使用普通静态文件服务器。
5. 只有坐标、没有文字地址的链接，如需反查完整省市区和门牌地址，可在“系统设置”填写高德地图 Web 服务 Key。Key 仅保存在当前浏览器；正式上线时应改为服务端环境变量或密钥管理服务，不能下发给普通用户浏览器。

当前自动里程使用区县中心点直线距离乘道路修正系数进行估算，适合原型演示和预估报价。正式生产化应接入高德、百度或腾讯地图的驾驶路线API，获得按道路、车型和实时路况计算的准确里程。

正式生产化时，还应将数据层接入Laravel、FastAPI等服务端API及数据库，并补充登录、多租户隔离、权限、审计日志、附件存储、备份恢复、财务结账和审批机制。
